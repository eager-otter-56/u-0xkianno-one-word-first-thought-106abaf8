# One Word, First Thought

Entry for the make.fun bounty "One Word, First Thought". The program
(`main.py`) writes exactly one word — the first that comes to mind — to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

The word: **petrichor** — the earthy scent released when rain falls on
dry soil. Vivid, specific, and surprising in nine letters.
